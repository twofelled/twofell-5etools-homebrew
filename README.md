## Install in 5etools

1. Open the 5etools Homebrew Manager.
2. Select **Load from URL**.
3. Paste the following link depending on what homebrew you want:
  - The Idol Compendium - https://raw.githubusercontent.com/twofelled/twofell-5etools-homebrew/refs/heads/main/book/Twofell%3B%20The%20Idol%20Compendium.json
